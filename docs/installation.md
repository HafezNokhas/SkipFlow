# Install SkipFlow

SkipFlow supports Android 8.0 and newer.

1. Go to the [latest SkipFlow release](https://github.com/HafezNokhas/SkipFlow/releases/latest).
2. Under **Assets**, download `SkipFlow-v0.5.1-beta.apk`.
3. Open the APK from your browser's downloads.
4. If Android blocks the installation, choose **Settings** and temporarily allow installs from that browser or file manager. Return to the APK and install it.
5. Open SkipFlow.
6. Select a language and read the Accessibility disclosure.
7. Open Android Accessibility settings and enable **SkipFlow automation service**.
8. Return to SkipFlow. Confirm that the service shows as connected and turn on Automation.
9. Open the official YouTube app and use it normally.

Android settings look different on Samsung, Xiaomi, Redmi, POCO, Motorola, and other devices. SkipFlow never enables Accessibility or changes battery settings automatically.

When updating, install the newer APK over the existing app. Do not uninstall first if you want to keep local settings and diagnostic history.
