# SkipFlow

SkipFlow is a small Android helper that waits for YouTube's official enabled **Skip ad** button and requests one click. It does not bypass countdowns or interact with ads that cannot be skipped.

> **Beta:** SkipFlow is still being tested with a small group. Features may not work on every phone or after YouTube updates.

## Download

### [Download SkipFlow](https://github.com/HafezNokhas/SkipFlow/releases/latest)

Download the APK attached to the latest GitHub Release. Do not download SkipFlow from unofficial mirrors.

## Requirements

- Android 8.0 or newer (API 26+)
- The official YouTube Android app
- Manual approval of the SkipFlow Accessibility Service

## Install and start

1. Open the latest [GitHub Release](https://github.com/HafezNokhas/SkipFlow/releases/latest).
2. Download `SkipFlow-v0.5.1-beta.apk`.
3. Open the downloaded file and allow installation from this source if Android asks.
4. Open SkipFlow and follow the setup guide.
5. Read the disclosure, open Android Accessibility settings, and enable SkipFlow.
6. Turn on Automation, then use YouTube normally.

See the detailed [installation guide](docs/installation.md).

## Permissions and privacy

SkipFlow uses Android Accessibility only to detect the official enabled skip control inside the official YouTube app. The app has no Internet permission and does not collect screen text, video, account information, passwords, device IDs, advertising IDs, browsing history, or personal data.

Read the full [privacy policy](PRIVACY.md).
